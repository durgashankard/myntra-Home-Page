# 🛍️ Myntra Home Page Clone

A responsive and visually rich clone of the Myntra homepage built using **HTML, CSS, and Bootstrap**.
This project replicates the UI structure of the popular e-commerce platform Myntra with custom styling and layout.

---

## 🚀 Live Demo

🔗 https://durgashankard.github.io/myntra-Home-Page/

---

## 📌 Project Overview

This project is designed to:

* Practice real-world UI cloning
* Improve frontend layout skills
* Work with Flexbox, Grid, and Bootstrap
* Understand modern e-commerce UI patterns

---

## ✨ Features

✅ Responsive Header Navigation
✅ Search Bar UI
✅ Profile, Wishlist & Bag Icons
✅ Promotional Marquee Banner
✅ Fixed Social Media Sidebar
✅ Multiple Banner Sections (Ads & Offers)
✅ Product Cards Grid Layout
✅ Attractive UI using Gradients & Shadows

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/your-username/myntra-clone.git
```

2. Open project folder:

```bash
cd myntra-clone
```

3. Open `index.html` in browser

---

## 🌐 Deploy on GitHub Pages

1. Push project to GitHub
2. Go to **Settings → Pages**
3. Select:

   * Branch: `main`
   * Folder: `/root`
4. Save

👉 Your project will be live!
